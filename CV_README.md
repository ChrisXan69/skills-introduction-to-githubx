# CV Generator

This repository contains a Python script to generate a professional CV PDF using ReportLab.

## Requirements

- Python 3.x
- reportlab 4.0.9

## Installation

Install the required dependencies:

```bash
pip install -r requirements.txt
```

## Usage

Run the script to generate the CV PDF:

```bash
python generate_cv.py
```

This will create a file named `CV_Christopher_Mendoza_Sanchez_Redesign.pdf` in the current directory.

## Features

- Two-column layout with sidebar and main content
- Custom color scheme (Navy Blue primary, Steel Blue accents)
- Professional formatting with custom styles
- Includes:
  - Contact information
  - Education
  - Technical skills (Software & ERP)
  - Technology & AI expertise
  - Leadership skills
  - Professional profile
  - Work experience
  - Featured projects

## Output

The script generates a professionally formatted PDF CV approximately 5KB in size, using the A4 page format with custom margins and styling.
